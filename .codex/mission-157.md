# GOAL

Enregistrer un événement à l'arrivée sur la page d'analyse, pour mesurer deux choses aujourd'hui invisibles : les clics sur le bouton fixe mobile, et l'écart entre « arrive sur la page d'analyse » et « lance une analyse ».

# DONE WHEN

1. Une arrivée sur la page d'analyse produit une ligne dans la vue des événements, avec le nom d'événement nouveau et la page correspondante.
2. Une arrivée depuis le bouton fixe mobile porte son origine interne dans la colonne prévue.
3. Le nombre de visites affiché par l'entonnoir, sur une période donnée, est identique avant et après cette mission. Démontre-le avec une mesure, pas une affirmation.
4. L'entonnoir affiche la nouvelle marche entre les visites et les analyses lancées.
5. Les scripts de test, de build, de lint et de vérification de types passent.
6. Le rapport donne le SQL de la migration s'il y en a une, prêt à coller, la liste des fichiers touchés, et le résultat des quatre scripts.
